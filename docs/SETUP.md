# 設置手順書（LINE文面作成アプリ）

この手順どおりに進めれば、アプリを自分専用で使えるようになります。
作業は大きく **5ステップ**です。パソコンで進めるのがおすすめです。

- ステップ1：Googleスプレッドシートとプログラム（GAS）を用意する
- ステップ2：初期設定（シート作成・APIキー・パスコード）
- ステップ3：アプリとして公開する（デプロイ）
- ステップ4：画面（PWA）をインターネットに公開する（GitHub Pages）
- ステップ5：スマホのホーム画面に追加する

専門用語はできるだけ避けています。わからないところはそのまま聞いてください。

---

## 事前に用意するもの

- Googleアカウント（スプレッドシートを使えるもの）
- Claude（Anthropic）の APIキー … `sk-ant-` で始まる文字列
  - 無い場合は https://console.anthropic.com/ で発行できます（クレジットの登録が必要です）

---

## ステップ1：スプレッドシートとプログラムを用意する

1. Googleドライブで新しい**スプレッドシート**を1つ作ります（名前は「LINE文面アプリ」など何でもOK）。
2. そのスプレッドシートのメニューで **拡張機能 → Apps Script** を開きます。
   - 別タブで「コードを書く画面（エディタ）」が開きます。
3. エディタに最初からある `コード.gs`（または `Code.gs`）を使って、この後ファイルを貼り付けていきます。

### プログラムの貼り付け方（手作業・clasp不要）

このプロジェクトの `gas/` フォルダにある **7つのファイル**を、Apps Script エディタに写します。

貼り付けるファイル：
`Main.gs` / `Auth.gs` / `Sheets.gs` / `Api.gs` / `Prompt.gs` / `Setup.gs` / `SeedData.gs`

手順：
1. エディタ左の「ファイル」の「＋」→「スクリプト」で新しいファイルを作り、名前を上の名前（例：`Main`）にします。拡張子 `.gs` は自動で付きます。
2. パソコンでそのファイル（例：`gas/Main.gs`）をテキストとして開き、中身を**全部コピー**して、エディタの同じ名前のファイルに**貼り付け**ます。
3. これを7ファイルぶん繰り返します。最初からあった `コード.gs` は中身を空にするか、削除してかまいません。
4. さらに、エディタの設定で **「appsscript.json」マニフェストファイルを表示する** をオンにし、`appsscript.json` の中身も `gas/appsscript.json` の内容に置き換えます。
   - （歯車の「プロジェクトの設定」→「`appsscript.json` マニフェスト ファイルをエディタで表示する」にチェック）
5. フロッピーのアイコンで**保存**します。

> clasp（コマンドで一括アップロードする方法）が使える人は、`gas/` フォルダを `clasp push` でまとめて反映してもOKです。うまくいかない場合は上の手作業で問題ありません。

## ステップ2：初期設定（シート作成・APIキー・パスコード）

1. スプレッドシートのタブに戻り、**ページを再読み込み**します。
2. 上のメニューに **「LINE文面アプリ」** が増えています（出ない場合は少し待って再読み込み）。
3. **LINE文面アプリ → 初期設定（シート作成）** をクリック。
   - 7つのシート（candidates ほか）が作られ、シーン・レベル・設定の初期データが入ります。
   - 途中で「許可が必要です」と出たら、自分のGoogleアカウントで**承認**してください。
4. **LINE文面アプリ → Claude APIキーを設定** をクリックし、`sk-ant-...` のキーを貼り付けます。
5. **LINE文面アプリ → パスコードを設定** をクリックし、ログイン用のパスコード（**8文字以上**）を決めて入力します。
   - これはアプリにログインするときの合言葉です。忘れないようにしてください。
6. **LINE文面アプリ → 接続テスト** をクリック。「接続成功」と出れば、AIとつながっています。
   - 失敗する場合はAPIキーを見直してください。

---

## ステップ3：アプリとして公開する（デプロイ）

アプリがスマホから通信できるように、「ウェブアプリ」として公開します。

1. Apps Script エディタの右上 **「デプロイ」→「新しいデプロイ」** をクリック。
2. 歯車アイコン →**「ウェブアプリ」** を選びます。
3. 設定を次のようにします。
   - 説明：なんでもOK（例「v1」）
   - **次のユーザーとして実行：自分**
   - **アクセスできるユーザー：全員**
4. **「デプロイ」** を押し、承認を求められたら承認します。
5. 表示される **「ウェブアプリのURL」**（`https://script.google.com/macros/s/...../exec`）を**コピー**します。
   - このURLは後で使います。メモしておいてください。

> あとでプログラムを更新したときは、「デプロイ → デプロイを管理 → 鉛筆マーク → バージョン『新しいバージョン』→ デプロイ」で反映します。URLは変わりません。

---

## ステップ4：画面をインターネットに公開する（GitHub Pages）

スマホで開く「画面」を、GitHub Pages という無料の仕組みで公開します。

1. GitHub（https://github.com/）でアカウントを作り、**新しいリポジトリ**を作ります。
   - 公開（Public）でOK。※画面のコードに秘密情報は入っていません。
2. このプロジェクトの **`web/` フォルダの中身**をリポジトリにアップロードします。
   - `index.html` がリポジトリの一番上（またはPagesで指定するフォルダの直下）に来るようにします。
3. **`web/config.js` を編集**して、ステップ3でコピーしたウェブアプリのURLを貼り付けます。
   ```js
   const GAS_URL = 'https://script.google.com/macros/s/XXXXXXXX/exec';
   ```
   - この1行だけ書き換えればOKです。
4. リポジトリの **Settings → Pages** を開き、
   - 「Build and deployment」の Source を **Deploy from a branch**
   - Branch を `main`（アップロードしたブランチ）、フォルダを `/ (root)` に設定して Save。
5. 数十秒〜数分すると、`https://ユーザー名.github.io/リポジトリ名/` のような**公開URL**が表示されます。

> `web/` の中身をそのままルートに置いた場合、アプリのURLは末尾に `/index.html` を付けなくても開けます。

---

## ステップ5：スマホのホーム画面に追加する

1. スマホの**ブラウザ**（iPhoneはSafari、AndroidはChrome推奨）で、ステップ4の公開URLを開きます。
2. パスコード（ステップ2で決めたもの）でログインできることを確認します。
3. ホーム画面に追加します。
   - **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
   - **Android（Chrome）**：右上メニュー → 「ホーム画面に追加」／「アプリをインストール」
4. 追加したアイコンから起動すると、全画面のアプリとして使えます。

---

## うまくいかないときは

- **ログインできない**：パスコードを確認。5回続けて失敗すると10分間ロックされます。10分待つか、スプレッドシートのメニューからパスコードを再設定してください。
- **「接続先が未設定です」と出る**：`config.js` のURL貼り付けを確認してください。
- **AIの応答が返らない／エラー**：接続テストをやり直し、APIキーとクレジット残高を確認してください。
- **画面を更新したのに古いまま**：アプリをいったん閉じて開き直すと新しい画面になります（キャッシュのため）。
- **シーンを増やしたい・並べ替えたい**：スプレッドシートの `scenes` シートを直接編集できます（`order` が小さい順に並びます。`active` を `FALSE` にすると非表示）。

---

## メモ：安全性について

- APIキーとパスコードは**スプレッドシート側（GAS）だけ**に保存され、公開される画面コードには入りません。
- 画面コードが公開されても、ログイン用トークンが無ければ何も操作できない設計です。
